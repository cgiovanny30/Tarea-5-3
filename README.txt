PROYECTO: DESCUBRE PUERTO RICO
Página web responsiva con HTML, CSS y Bootstrap

Autor: Christopher Maldonado
Año: 2026


DESCRIPCIÓN

En esta tarea desarrollé un sitio web responsivo dedicado a diferentes
lugares de Puerto Rico. El sitio fue creado utilizando HTML5, CSS y
Bootstrap. El objetivo fue crear una página que pudiera verse
correctamente tanto en computadoras como en dispositivos móviles.

El sitio está compuesto por varias páginas que se encuentran conectadas
por medio de una barra de navegación.


PÁGINA DE INICIO

La página index.html funciona como la página principal. Incluye una barra
de navegación creada con Bootstrap, una imagen de fondo, un título y una
sección de "Acerca de mí".

La información del propietario utilizada en esta sección es ficticia.
También se añadió un botón que permite ir directamente a la página de
contacto.


PÁGINA DE LUGARES

La página lugares.html funciona como un pequeño portafolio de lugares
de Puerto Rico.

Utilicé tarjetas de Bootstrap para presentar Viejo San Juan, El Yunque
y las playas de Puerto Rico. Cada tarjeta incluye una imagen, una
descripción y un botón "Leer más".

Los botones permiten acceder a información adicional ubicada en la
página detalle.html.


PÁGINA DE CONTACTO

La página contacto.html contiene un formulario ficticio con campos para
nombre, correo electrónico y mensaje.

El formulario utiliza estilos y validación de Bootstrap. Si el usuario
intenta enviar el formulario sin completar los campos, la página muestra
mensajes indicando qué información falta.

También se incluyeron un correo electrónico y un número de teléfono
ficticios.


DISEÑO RESPONSIVO

Para lograr un diseño responsivo utilicé las clases de Bootstrap y
estilos CSS personalizados. La distribución de los elementos cambia
dependiendo del tamaño de la pantalla.

Por ejemplo, en pantallas pequeñas la barra de navegación utiliza un
menú desplegable y las tarjetas se muestran de manera vertical.


PERSONALIZACIÓN

El archivo styles.css contiene cambios personalizados en colores,
espaciado, bordes, botones, imágenes y otros elementos visuales.

Estos estilos fueron utilizados junto con Bootstrap para crear una
apariencia sencilla, organizada y funcional.


ARCHIVOS PRINCIPALES

index.html - Página de inicio.
lugares.html - Portafolio de lugares.
detalle.html - Información adicional de los lugares.
contacto.html - Formulario de contacto.
styles.css - Estilos personalizados.
imagenes - Recursos visuales utilizados en el sitio.
