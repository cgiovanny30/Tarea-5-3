Acerca de mí

¡Hola! Soy Christopher Maldonado, un joven puertorriqueño apasionado por conocer diferentes lugares de la isla. Creé este sitio para compartir algunos de los destinos que considero interesantes para visitar en Puerto Rico.

Mi objetivo es mostrar parte de nuestra cultura, naturaleza y belleza mientras practico el desarrollo de páginas web utilizando HTML, CSS y Bootstrap.
